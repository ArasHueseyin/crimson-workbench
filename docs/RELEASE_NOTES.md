## Crimson Workbench 0.10.0

**[Download the Windows installer](https://github.com/ArasHueseyin/crimson-workbench/releases/download/v0.10.0/Crimson-Workbench_0.10.0_x64-setup.exe)** · One setup includes Workbench and its optional game modules.

- **Unlock journal knowledge:** complete 3,939 supported journal entries from the Marketplace. Each selected save gets its own preview, with only missing entries and levels added. Existing knowledge, skill points and unrelated save data are preserved. Includes people, places, creatures, recipes and quest information, so expect story spoilers. Requires a closed game; a backup is created first.
- **Gliding speed fixed:** speed changes target the fast X glide, keeping ordinary wing gliding unchanged. The corrected 250% setting was confirmed in game.
- **Mount registration fixed:** new mounts no longer compete for the same active mount assignment. The catalog now checks player-riding interactions and excludes NPC-only variants.
- **Special-container items:** Item Picker identifies unsupported storage destinations, including Kuku storage, before sending a grant. It explains the restriction so ordinary item grants can continue. Direct grants into those containers are not included.
- **Restricted-region timer:** its separate Install/Remove action now preserves existing archive mods and reports installation status correctly.

Windows x64 · supported game EXE **1.0.0.2976** · unsigned Windows binaries. Built and tested through GitHub Actions; **SHA256SUMS.txt** accompanies the downloads. Private saves, local tools and game assets are excluded.
