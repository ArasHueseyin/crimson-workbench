# Crimson Workbench 0.8.0

This is a regular release, with an English interface and a free, built-in mod marketplace. No account, payment or separate mod download is required.

The seven included mods are:

- **Larger lion:** a 30% larger shared lion model; lionesses are unchanged.
- **Faster mounts:** a 30% higher movement speed stat for the circus lion and all five Rokade stages.
- **No mount stamina cost:** no stamina cost and boosted regeneration for those mounts; player stamina is unchanged.
- **All skills:** all 140 main-character abilities at maximum in one selected save, with a backup and preserved available points and inventory.
- **No sleep cooldown:** sleep or wait again without an extra delay. The former personal one-second cooldown is now zero; other native validity checks remain.
- **30-hour sleep:** choosing the existing 12-hour option advances the game clock by 30 hours. The in-game menu label still says 12 hours; other choices remain unchanged.
- **Blackstar anywhere:** lifts Blackstar's regional, city and altitude restrictions, boosts stamina regeneration, reduces summon cooldown to one second and extends riding duration to 1,000 minutes. Quest, indoor and final placement checks can still prevent summoning. Existing saved timers are not rewritten.

Use **Install mod** or **Remove mod** on each new runtime card with the game closed. Workbench stays open; Windows may request administrator permission. Start the game afterward to load the ASI. **Import & update mod** recognizes the original personal versions by exact hash and backs them up before updating. Unknown or modified files are protected. Interrupted operations can be recovered from the card. These three ASI actions are independent of the combined archive plan and do not edit saves.

The setup and portable ZIP include all three marketplace payloads. No separate download or PowerShell command is needed. Automated checks cover immediate cooldown clearing, 288 calendar cases, actual loader admission, module lifecycles, legacy backups, foreign-file protection and transaction rollback/recovery. The Blackstar card packages the existing personal implementation; it does not establish that every location permits summoning. No new in-game validation is claimed by automated tests.

The three archive-recipe cards use **Select mod / Deselect mod** switches. Selection only changes the draft. Review the combined plan and use **Live apply & restore** with the game closed to install it. All skills is a separate save edit that requires explicit confirmation. Existing unmanaged archive mods can block live apply; they are not silently overwritten or removed.

Download **`Crimson-Workbench_0.8.0_x64-setup.exe`** for the normal Windows installation. The single installer includes Workbench, Live Items, Extra Sockets and their loader. It detects the Steam game folder or lets you select it; no extra ZIP or PowerShell commands are needed. A portable package and a separate runtime-mod package are also available.

Windows x64 and your own compatible game installation are required. Runtime modules and the bundled marketplace recipes require the supported EXE **1.0.0.2976** and verified source data. Close the game for installation and archive/save edits, then restart it to load the runtime modules. Older or conflicting runtime modules may require removal using their original package before updating.

Item names and descriptions follow the Steam game language when **Automatic** is selected; the Workbench interface stays English. Other platforms and separate in-game language overrides may require a manual catalog language choice.

Packages are built and tested by GitHub Actions. **`SHA256SUMS.txt`** contains download checksums. Windows binaries are currently unsigned, so Windows may display an unknown publisher. No game archives, personal saves or configurations are distributed.
