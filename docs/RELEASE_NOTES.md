# Crimson Workbench 0.6.3 Preview

The Workbench interface, installer and Markdown documentation are now in English. Item names and descriptions automatically follow the installed game language recorded by Steam, with English as the fallback. Existing manual language preferences are preserved; select **Automatic** to enable detection on an older installation. Separate in-game language overrides and Epic/Game Pass language settings still require a manual catalog selection.

Download **`Crimson-Workbench_0.6.3_x64-setup.exe`** for the normal Windows installation. The single installer includes Workbench, Live Items, Extra Sockets and their loader. It detects the Steam game folder or lets you select it. No additional ZIP or PowerShell commands are required. Identical installed modules retain their personal configuration; conflicting mods are not overwritten. A portable package and separate runtime-mod package remain available.

Windows x64 and your own compatible game installation are required. Setup downloads WebView2 if it is missing. The live modules require the exact supported EXE **1.0.0.2976**; full in-game validation remains pending. This is a preview release, and the Windows binaries are currently unsigned. Checksums are provided in `SHA256SUMS.txt`.

See the [installation guide](https://github.com/ArasHueseyin/crimson-workbench/blob/v0.6.3/docs/INSTALLATION.md) for compatibility, automatic language selection, data locations and module removal. No game archives, saves or personal configurations are distributed.
