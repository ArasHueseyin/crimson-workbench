# Crimson Workbench 0.7.0

This is a regular release, with an English interface and a free, built-in mod marketplace. No account, payment or separate mod download is required.

The four included mods are:

- **Larger lion:** a 30% larger shared lion model; lionesses are unchanged.
- **Faster mounts:** a 30% higher movement speed stat for the circus lion and all five Rokade stages.
- **No mount stamina cost:** no stamina cost and boosted regeneration for those mounts; player stamina is unchanged.
- **All skills:** all 140 main-character abilities at maximum in one selected save, with a backup and preserved available points and inventory.

The game-mod cards use **Select mod / Deselect mod** switches. Selection only changes the draft. Review the combined plan and use **Live apply & restore** with the game closed to install it. All skills is a separate save edit that requires explicit confirmation. Existing unmanaged archive mods can block live apply; they are not silently overwritten or removed.

Download **`Crimson-Workbench_0.7.0_x64-setup.exe`** for the normal Windows installation. The single installer includes Workbench, Live Items, Extra Sockets and their loader. It detects the Steam game folder or lets you select it; no extra ZIP or PowerShell commands are needed. A portable package and a separate runtime-mod package are also available.

Windows x64 and your own compatible game installation are required. Runtime modules and the bundled marketplace recipes require the supported EXE **1.0.0.2976** and verified source data. Close the game for installation and archive/save edits, then restart it to load the runtime modules. Older or conflicting runtime modules may require removal using their original package before updating.

Item names and descriptions follow the Steam game language when **Automatic** is selected; the Workbench interface stays English. Other platforms and separate in-game language overrides may require a manual catalog language choice.

Packages are built and tested by GitHub Actions. **`SHA256SUMS.txt`** contains download checksums. Windows binaries are currently unsigned, so Windows may display an unknown publisher. No game archives, personal saves or configurations are distributed.

See the [installation guide](https://github.com/ArasHueseyin/crimson-workbench/blob/v0.7.0/docs/INSTALLATION.md) and [marketplace guide](https://github.com/ArasHueseyin/crimson-workbench/blob/v0.7.0/docs/MARKETPLACE.md).
