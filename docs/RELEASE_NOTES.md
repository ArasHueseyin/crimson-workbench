# Crimson Workbench 0.9.0

Download **`Crimson-Workbench_0.9.0_x64-setup.exe`** for Windows. One installer includes Workbench, the game-module loader and all optional modules.

- **35 mod cards:** individual skill unlocks, contribution points, inventory and stacks, player/mount movement and protection, crafting, auto-loot and selected consumables.
- **New controls:** Force Palm height up to 100×, independent stamina/spirit protection, Axiom reach from 2× to 5× and gliding speed up to 500%.
- **Live panels:** time/weather, photo mode and teleport after module setup. Item Picker also works while playing. Other installation, archive/save and startup-setting changes require a closed game.
- **Easier browsing:** search and filters, exact inputs, retained drafts, clearer status and errors, accessible dialogs and consistent save selection.

Requires **Windows x64 and the exact supported game EXE 1.0.0.2976**. Compatibility checks refuse unsupported or conflicting files. Automated tests cover implementation behavior; broader in-game testing of new features remains pending.

When upgrading from another base-runtime package, remove its modules with that package's original uninstaller first; personal socket data is preserved. Optional Marketplace modules use their own guarded update workflow.

Packages are built by GitHub Actions and include **SHA256SUMS.txt**. Windows binaries are unsigned, so an unknown-publisher warning may appear. Game archives, saves, personal settings and local developer tools are excluded.
